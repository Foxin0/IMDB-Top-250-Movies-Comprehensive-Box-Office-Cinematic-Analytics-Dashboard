# IMDB-Top-250-Movies-Comprehensive-Box-Office-Cinematic-Analytics-Dashboard
Project Overview: An end-to-end data visualization project built in Power BI examining a curated dataset of IMDB's Top 250 movies. The dashboard delivers deep-dive analytics into global box office gross, ticket sales volume, genre breakdowns, runtime metrics, and top-grossing directors and writers to uncover historical industry trends.

Tech Stack: Power BI, Power Query, DAX, Data Modeling, Advanced Excel.

Key Insights & Results:

Animation and Action genres dominate total box office gross revenue within the top-tier cinematic dataset.

Correlated high critical acclaim (IMDB ratings averaging ~8.0) with massive commercial box office returns.

Successfully transformed complex movie databases into a structured, dynamic 3-page interactive dashboard (Main Dashboard, Revenue & Breakdown, and Movie & Cast Details).
